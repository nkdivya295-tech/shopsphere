# ShopSphere — Smart Shopping, Better Choices

A responsive frontend-only e-commerce UI/UX prototype built with HTML, CSS, and vanilla JavaScript, aligned with the competition brief in the supplied Turing Club UI/UX Frontend PDF.

## Run locally
1. Extract the ZIP folder.
2. Open the `shopsphere_website` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Internet is needed for Google Fonts and the remote Unsplash product images.

## Included features
- Responsive homepage, product catalogue, and category filters
- Search and sorting by price/rating
- Wishlist and shopping bag with quantity updates and subtotal
- Smart Choice comparison (up to four products), lowest-price highlight, and price/rating trade-off explanations
- Explainable rule-based product recommendations
- Demo checkout with a clear no-payment disclaimer
- Newsletter interaction feedback
- Keyboard focus states, escape-to-close side panel, and reduced-motion support

## Important limitations
This is a frontend prototype. Cart and wishlist data are in memory and reset on refresh. Checkout does not process payments or create real orders. Recommendations use sample catalogue prices and ratings; they are not a trained AI model and are not personalized from private data.

## Design decisions
The PDF emphasizes clarity, hierarchy, consistency, feedback, accessibility, responsiveness, subtle reversible micro-interactions, testing, and a clear presentation story. The UI uses a restrained cream/charcoal/orange/green palette, visible states, mobile breakpoints, keyboard focus, and short transitions.
